### 在做的事

- **接线** — 把 Claude Code、Codex、Cursor、Cherry Studio 这类客户端，接到你自己选的网关上
- **排障** — `401` `402` `403` `404` `429` 分别意味着什么，先查哪一层
- **算账** — 预扣计费下，为什么"免费模型"也会报余额不足
